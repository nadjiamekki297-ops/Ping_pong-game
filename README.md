# Ping_pong-game
# Ping Pong 🏓
#pip install pygame
لعبة بينغ بونغ لاعبين اثنين، مكتوبة بـ Python (turtle).

## التشغيل
1. ثبّت Python من python.org
2. حمّل ملف main.py
3. شغّله بالأمر:
   python main.py

## طريقة اللعب
- اللاعب 1 (الأزرق): W فوق، S تحت
- اللاعب 2 (الأحمر): السهم فوق / تحت
- الهدف: اضرب الكرة وما تخليهاش تفوتك، وكل ما تفوت من لاعب، الخصم ياخذ نقطة.
